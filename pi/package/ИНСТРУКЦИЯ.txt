УСТАНОВКА НОВОЙ ВЕРСИИ ПРОГРАММЫ НА МАШИНУ
==========================================

Что в архиве
  Auto_Cleaner_APPM_rspb    - новая программа
  install_from_computer.sh  - установка с компьютера одной командой
  install.sh                - установка (запускается на самой Pi)
  rollback.sh               - возврат предыдущей версии (на самой Pi)
  ВЕРСИЯ.txt                - какая версия собрана

Что нужно
  - компьютер в одной сети с машиной (кабель или Wi-Fi машины);
  - адрес Pi машины: IP (например 192.168.68.140) или её имя в сети (например appm-012.local);
  - пароль пользователя knight на Pi (если вход по ключу не настроен);
  - машина стоит, уборка выключена (программа перезапустится на несколько секунд).

Перед заменой установка проверяет, что программа подходит этой Pi. Если нет - пишет причину и НИЧЕГО
не меняет. Затем показывает имя и серийный номер Pi - сверьтесь, что это нужная машина, - и спрашивает
подтверждение: ответить y. Старая версия сохраняется, настройки машины не меняются.


СПОСОБ 1. Компьютер с Linux или macOS - одна команда
-----------------------------------------------------
Сначала перейти в папку, где лежит архив, например:
    cd ~/Загрузки
затем:
    tar -xzf Auto_Cleaner_*.tar.gz
    cd Auto_Cleaner_*/
    bash install_from_computer.sh АДРЕС
Пароль Pi спросят один раз (и, возможно, ещё раз для sudo). В конце должно быть
«Готово: новая версия запущена» и последние строки лога программы.


СПОСОБ 2. Компьютер с Windows (PowerShell) или вручную
-------------------------------------------------------
1. Распаковать архив (в PowerShell: tar -xzf Auto_Cleaner_*.tar.gz) и скопировать папку на Pi:
       scp -r Auto_Cleaner_ПАПКА knight@АДРЕС:/home/knight/updates/
   (если папки updates нет: ssh knight@АДРЕС mkdir -p /home/knight/updates)
2. Зайти на Pi и установить:
       ssh -t knight@АДРЕС
       cd /home/knight/updates/Auto_Cleaner_ПАПКА
       sudo bash install.sh
Вместо компьютера можно подключить к Pi клавиатуру: Ctrl+Alt+F2, войти как knight, скопировать папку
с флешки и выполнить те же cd и sudo bash install.sh.


ПОСЛЕ УСТАНОВКИ
---------------
На экране машины программа запустилась, в журнале на экране нет новых ошибок.
Дальше - проверки из docs/machine_checks.md (их даёт разработчик).

Если новая версия работает плохо - вернуть прежнюю:
       ssh -t knight@АДРЕС sudo bash /home/knight/updates/Auto_Cleaner_ПАПКА/rollback.sh
Повторный запуск rollback.sh снова включит новую.

Если установка пишет «сервис my-app сейчас не работает»
   Узнать, какую программу запускает автозапуск:  systemctl cat my-app
   (в строке ExecStart - скрипт запуска, в нём путь к программе), и запустить установку с этим путём:
       sudo bash install.sh /путь/к/Auto_Cleaner_APPM_rspb

Лог программы (если нужно прислать разработчику)
       ssh knight@АДРЕС "journalctl -u my-app --since today" > log.txt
